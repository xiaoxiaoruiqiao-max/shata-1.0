# 沙塔1.0

上证180版与红利版 ETF 动量轮动看板。Python 标准库服务与原生网页，无需安装前端构建工具。

## 快速启动

需要 Python 3.10 或更新版本，测试环境为 Python 3.12。

```shell
cd etf-momentum-dashboard
python -m unittest -v test_pilot test_shadow test_dual test_audit
python dashboard.py check
python dashboard.py serve --port 8765 --no-schedule
```

打开 http://127.0.0.1:8765/?v=9 。Windows 可用 `py -3` 替代 `python`。
首次查看建议保留 `--no-schedule`，不会联网采集或启动前瞻模拟；需要正常自动采集时去掉该参数。不要同时启动两个服务实例。

## 功能与口径

- 两版历史净值、年度/月度收益、动量轨迹和同步持仓日历。
- 上证180原版200笔与红利版195笔历史模拟交易，支持独立筛选、分页，收益含权益调整与单边万二。
- 两版各50万元的独立前瞻模拟，以及按券商回报手工登记的独立实盘账本，不连接券商下单。
- 包内公开历史截至2026-11-13。上证180原版自2013-01-04起，红利版及双版共同历史自2013-09-02起。各区块起点和策略约束不同，不应直接混同。
- 日线双源核对后才续算。真实盘口缺失时跳过，不以日线补造盘中成交。

## 状态与部署

仓库不含实盘账本、前瞻状态、日志、备份、密钥或本机专用任务配置。正常首次启动会建立自己的运行状态；延续旧账户须单独迁移完整状态及备份。

默认仅监听127.0.0.1，网页无账号系统。服务应放在受保护的SSH隧道或HTTPS及访问认证之后。反代域名需用 `ETF_ALLOWED_HOSTS` 明确配置（主机名，逗号分隔），保持原Host。运行数据应放在 `ETF_STATE_DIR` 指定的持久目录；Docker Compose已配置独立卷。

关机、休眠或退出服务会停止实时采集。Windows计划任务不随源码自动安装，另一台电脑需单独设置守护方式。服务器部署尚未执行。上传GitHub仅保存源码，不代表网页已在公网运行。

历史模拟结果不代表未来收益；历史回测、前瞻模拟和真实成交必须分别解读。
